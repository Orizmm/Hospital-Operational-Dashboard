# Hospital Operational Dashboard Analysis

## 📌 Project Overview
This project focuses on analyzing hospital outpatient service performance through an interactive dashboard. It aims to identify operational inefficiencies and improve service quality using data-driven insights.

## 🎯 Objectives
- Analyze daily patient visit trends
- Evaluate distribution of payment methods (BPJS, insurance, general)
- Identify clinics with the longest waiting times
- Investigate service issues for specific patient groups

## 🛠️ Tools & Technologies
- Google Looker Studio (Data Visualization)
- SQL / Spreadsheet (Data Processing & Cleaning)
- Python for Data Cleaning & Transformation Techniques

## 📊 Key Insights
- Patient visits peak on specific days, increasing queue risk
- Majority of patients use BPJS, indicating high operational load
- Certain clinics have significantly longer waiting times
- Elderly BPJS patients experience extreme delays in the morning
